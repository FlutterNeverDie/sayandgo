7. 비용 절감

장치내용효과
페이지네이션limit(10) + startAfter 커서, "더 보기" 버튼 (자동 무한 스크롤 안 함)보는 만큼만 읽기
메모리 캐시TanStack Query: 질문 목록 60초, 가게 정보 · 개수 10분뒤로 가기 · 재방문 읽기 0
기기 캐시Firestore persistentLocalCache저장된 내용 먼저 표시
손님은 실시간 구독 안 함getDocs 한 번, 당겨서 새로고침계속 열어 둬도 추가 과금 없음
낙관적 추가질문 · 답변 저장 후 목록 재조회 없이 화면에 바로 반영쓰기 뒤 읽기 0
사장님 구독 최소화"새 질문" 탭만 구독, 화면이 꺼지면 구독 해제바뀐 문서만 과금
개수 표시count() = 1,000건당 읽기 1, 10분 캐시문서를 다 읽지 않음
규칙 안 읽기규칙의 get · exists도 읽기로 과금 → 질문 쓰기 1건에 약 4회로 고정예측 가능
Storage 0사진 없음, QR · 공유 이미지는 브라우저에서 생성저장 · 전송 비용 없음
CloudFront해시 붙은 JS · CSS 1년 캐시, index.html만 매번 확인. 폰트는 필요한 글자만(서브셋)전송량 최소
광고 지연 로딩광고는 화면에 들어올 때만 불러옴첫 화면 빠름

손님 첫 방문 약 11~14 읽기 → 무료 한도(하루 5만)로 하루 약 3,500~4,500 방문. 넘으면 종량제 전환.
