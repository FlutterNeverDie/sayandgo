큐플레이스 운영 · 정책 설계

금칙어 · 사장님 관리 기능 · 신고 · 약관과 정책 · 추가로 필요한 것 / 2026-11-19
전체 구조는 design-proposal.html, 이 문서의 9~10장이 최종 데이터 구조와 보안 규칙입니다.

00요약

  • 에스크에서 익숙한 기능(익명 질문, 골라서 답하기, 삭제, 차단, 신고, 답변 공유)을 매장용으로 그대로 갖춥니다.
  • 서버 없이 도배 제한 · 차단 · 신고 중복 방지를 하려고 손님도 화면에 보이지 않는 익명 로그인을 씁니다. 손님은 아무것도 입력하지 않습니다.
  • 안전장치는 4겹: 금칙어 자동 차단 → 사장님 숨기기 · 삭제 · 차단 → 신고 3건이면 자동 가림 → 운영자 확인.
  • 출시 전 필요한 문서: 이용약관, 개인정보처리방침, 운영정책, 권리침해 신고 안내. 가입 화면에 필수 동의 3개.
  • 서버 없이 안 되는 것 하나: 새 질문 푸시 · 메일 알림. 앱 안 배지로 대신합니다(8장).

출시 범위

구분기능
출시 필수손님 익명 로그인 + 30초 쓰기 간격(규칙으로 강제), 공통 금칙어 + 가게별 금지어, 답변 작성 · 수정 · 삭제, 숨기기, 삭제(5초 되돌리기), 여러 개 선택, 작성자 차단 · 해제, 신고 + 자동 가림, 질문 받기 일시정지, 소개 한 줄, 미답변 공개 설정, 이용 제한 가게 화면, 약관 · 개인정보 · 운영정책 · 권리침해 신고 페이지, 가입 동의, 운영자 화면(최소)
출시 직후답변 공유 이미지(인스타 스토리 크기), 질문 하나짜리 링크, 자주 묻는 질문 고정, 받은 질문 · 답변 수 표시, 홈 화면에 추가(PWA)
나중에새 질문 알림(서버 필요), 카카오톡 링크 미리보기에 상호명 표시(엣지 함수 필요), 데이터 백업, "나도 궁금해요"

02손님 익명 로그인

손님이 처음 질문 · 신고를 보낼 때 signInAnonymously()를 조용히 실행합니다. 화면에는 아무것도 뜨지 않고, 기기마다 임의의 번호가 하나 생깁니다(브라우저 저장소에 유지).

이걸로 되는 것방법
도배 제한 (진짜로 강제)질문을 쓸 때 throttle/{익명번호}의 마지막 작성 시각을 같이 갱신해야 하고, 규칙이 "30초 안 지났으면 거부"
작성자 차단질문마다 작성자 번호를 별도 문서(authors)에 두고, 차단 목록에 있으면 규칙이 거부
신고 한 사람당 한 번신고 문서 ID를 질문ID_익명번호로 만들어, 같은 사람이 두 번 만들 수 없게
내가 쓴 질문 삭제작성자 번호가 같으면 삭제 허용. 화면엔 "내 질문" 표시
  • Firebase Auth를 Identity Platform으로 업그레이드하지 않으면 익명 로그인은 무료입니다.
  • 사장님 계정 페이지에서는 익명 로그인을 쓰지 않습니다(사장님은 이메일 로그인).
  • 브라우저 데이터를 지우거나 다른 브라우저를 쓰면 새 번호가 생겨 차단 · 제한을 피할 수 있습니다. 서버 없이 할 수 있는 최선이고, 매장 규모의 장난에는 충분합니다.
익명성 범위를 정직하게: 사장님도 운영자도 누가 썼는지(이름 · 연락처 · IP)는 알 수 없습니다. 다만 차단 기능 때문에 사장님 계정은 기술적으로 "같은 기기에서 쓴 질문끼리"를 묶을 수 있습니다. 화면에는 보여 주지 않지만 개인정보처리방침에는 이 사실을 적습니다.

03금칙어

단계내용관리
공통 금칙어나라별 대표 욕설 · 비방 몇 개씩 (ko · en · ja · zh · es). 소문자로 바꿔 포함 여부만 비교코드 안 상수 bannedWords.ts. 바꾸려면 재배포
가게별 금지어사장님이 직접 추가 (최대 30개, 각 20자). 예: 직원 이름, 경쟁 가게 이름, 특정 메뉴 비하 표현설정 화면. 가게 문서 blockedWords
  • 적용 대상: 손님 질문(공통 + 가게별), 상호명 · 소개(공통). 사장님 답변에는 적용하지 않고 신고로 처리.
  • 걸렸을 때: "이 표현은 등록할 수 없어요. 다른 말로 써 주세요." 어떤 단어인지는 알려 주지 않습니다.
  • 한계: 화면에서만 검사합니다. 가게별 금지어는 가게 문서에 들어 있어 기술적으로 누구나 읽을 수 있으니 설정 화면에 "손님에게 보이지는 않지만 비밀 정보는 넣지 마세요" 안내.

04사장님 관리 기능

기능동작화면
답변작성 · 수정 · 삭제. 1~1,000자. 답변을 지우면 다시 "답변 전"으로질문 카드 아래 입력창. 수정하면 "수정됨" 표시
숨기기공개 목록에서만 빠지고 사장님 화면엔 남음. 언제든 다시 공개카드 메뉴 → 숨기기. "숨김" 탭에서 모아 보기
삭제완전히 지움. 작성자 기록도 같이 삭제"삭제했어요 · 되돌리기" 토스트 5초 뒤에 실제 삭제
여러 개 선택숨기기 · 삭제를 한 번에 (배치)상단 "선택" → 체크 → 하단 "삭제 12개"
작성자 차단그 기기에서 이 가게로 더 이상 질문 못 보냄카드 메뉴 → 차단 → "차단만 / 차단하고 삭제"
차단 해제설정 → 차단 목록(차단일 + 질문 앞부분 20자) → 해제-
질문 받기 일시정지켜면 손님 화면 입력창 대신 "지금은 질문을 받지 않아요" + 기존 목록은 그대로받은 질문함 상단 스위치
답 안 한 질문 공개끄면 답변한 질문만 손님에게 보임 (기본 켜짐)설정
소개 한 줄상호명 아래 표시, 60자설정
자주 묻는 질문 고정 (출시 직후)답변한 질문을 최대 3개 맨 위에 고정. "와이파이 비번?", "주차 돼요?"카드 메뉴 → 맨 위에 고정

차단 확인 시트 문구

이 질문을 보낸 기기에서는 앞으로 질문을 보낼 수 없어요. 누가 보냈는지는 큐플레이스도 사장님도 알 수 없어요.

[차단만 하기] [차단하고 질문 삭제]

차단된 손님이 보내면 "지금은 이 가게에 질문을 보낼 수 없어요"만 보여 주고 차단됐다는 사실은 알리지 않습니다.

05신고

신고 대상과 사유

  • 대상: 질문(답변 포함 한 묶음), 가게(상호명 · 소개 · 답변 전반). 질문 카드의 "⋯" 메뉴, 가게 페이지 맨 아래 "이 가게 신고".
  • 사유: 욕설 · 비하 / 개인정보 노출 / 광고 · 도배 / 음란 · 불쾌 / 허위사실 · 명예훼손 / 기타(300자까지 설명).

처리 흐름

  1. 손님(익명 로그인)이 신고 → reports 문서 생성 + 질문의 reportCount +1 (한 배치, 한 사람당 한 번).
  2. 3건이 되면 그 자리에서 자동으로 가려짐(hidden: true, hiddenBy: "report"). 보안 규칙이 같은 배치 안에서 강제하므로 서버가 필요 없습니다.
  3. 사장님 화면에는 "신고로 가려짐" 표시. 사장님이 다시 공개하거나 삭제할 수 있습니다.
  4. 운영자가 관리자 화면에서 신고 목록 확인 → 복구 / 가림 유지(운영자 가림은 사장님이 풀 수 없음) / 삭제 / 가게 이용 제한.

신고 완료 문구

신고가 접수됐어요. 여러 명이 신고하면 바로 가려지고, 운영팀이 확인해요.

권리침해 신고 (법적 절차)

정보통신망법 제44조의2에 따라, 명예훼손 · 사생활 침해를 당한 사람이 삭제를 요청하면 운영자는 해당 글을 가리는 임시조치(최대 30일)를 해야 합니다. 앱 안 신고와 별도로 이메일 접수 창구를 둡니다.

권리침해 신고 안내 (초안)

큐플레이스의 글 때문에 명예가 훼손되거나 사생활이 침해됐다면 아래 내용을 적어 [운영 이메일]로 보내 주세요.

  1. 신고하는 분의 이름과 연락처 (대리인이면 위임장)
  2. 문제가 된 글의 링크 또는 가게 링크와 글 내용
  3. 어떤 권리가 어떻게 침해됐는지와 그 근거

접수되면 지체 없이 해당 글을 가리고(임시조치), 가게 사장님에게 알려 드려요. 글을 쓴 손님은 익명이라 따로 알릴 수 없어요. 30일 안에 이의 제기가 없거나 침해가 분명하면 삭제해요.

06운영자 화면

  • 권한: 운영자 계정에 admin: true 표시(custom claim)를 붙입니다. 서버 함수가 아니라 이 맥에서 한 번 실행하는 스크립트(scripts/set-admin.mjs, 서비스 계정 키는 git에 올리지 않음)로 처리합니다.
  • 경로: /admin. 운영자가 아니면 404처럼 보이게.
  • 화면: 신고 대기 / 처리됨 탭. 각 항목에 신고 사유 · 건수 · 원문 · 가게명 · 바로가기.
  • 조치: 복구, 가림 유지, 삭제, 가게 이용 제한(status: "suspended") · 해제, 신고 처리 완료 표시.
  • 이용 제한된 가게: 손님 화면 "운영정책 위반으로 이용이 제한된 가게예요", 사장님은 로그인은 되지만 답변 · 설정 변경 불가 + 사유 안내.

이용약관 조항 구성

  1. 목적
  2. 정의: 서비스, 사장님 회원, 손님, 게시물(질문 · 답변 · 상호명 · 소개)
  3. 약관의 효력과 변경 (변경 7일 전 공지, 불리한 변경은 30일 전)
  4. 회원가입 (만 14세 이상, 계정당 가게 하나)
  5. 계정 관리 책임 (비밀번호 관리는 회원 책임)
  6. 서비스 내용 (익명 질문 수신 · 답변 · 링크 · QR, 무료 제공)
  7. 게시물의 책임: 질문은 작성한 손님, 답변 · 상호명 · 소개는 사장님 책임. 사장님은 자기 가게 페이지를 관리할 수 있음
  8. 금지 행위 (운영정책으로 연결)
  9. 게시물 가림 · 삭제 · 임시조치
  10. 이용 제한과 해지 (반복 위반 시 가게 이용 제한, 회원은 언제든 탈퇴)
  11. 광고 게재 (손님 화면에 광고가 표시될 수 있음)
  12. 게시물 이용: 서비스 화면 표시에 필요한 범위에서만 사용, 탈퇴 · 삭제 시 함께 삭제
  13. 서비스 변경 · 중단 (사전 공지)
  14. 면책 (무료 서비스, 손님 글의 내용과 정확성, 천재지변 · 외부 서비스 장애)
  15. 준거법 · 관할 (대한민국 법, 운영자 주소지 관할 법원)

큐플레이스는 손님이 가게에 익명으로 질문과 의견을 남기는 곳이에요. 모두가 편하게 쓸 수 있도록 아래 글은 등록되지 않거나 가려지고, 삭제될 수 있어요.

  • 욕설, 비하, 혐오 표현
  • 이름 · 전화번호 · 주소 · 차량번호처럼 다른 사람을 알아볼 수 있는 정보
  • 사실이 아닌 내용으로 가게나 직원의 평판을 해치는 글
  • 음란하거나 폭력적인 내용
  • 광고 · 홍보, 같은 내용 반복
  • 범죄를 부추기거나 법을 어기는 내용

이렇게 처리해요

  1. 일부 표현은 등록 단계에서 자동으로 막혀요.
  2. 사장님은 자기 가게에 온 질문을 숨기거나 지우고, 보낸 기기를 차단할 수 있어요.
  3. 여러 명이 신고한 글은 바로 가려지고 운영팀이 확인해요.
  4. 사장님의 답변 · 상호명도 같은 기준을 따라요. 위반이 반복되면 가게 이용이 제한될 수 있어요.
  5. 명예훼손 · 사생활 침해는 권리침해 신고로 알려 주세요.

10보안 규칙 전체

rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {

    // ---------- 공통 ----------
    function signedIn() { return request.auth != null; }                  // 익명 손님 포함
    function isAnon()   { return signedIn() && request.auth.token.firebase.sign_in_provider == 'anonymous'; }
    function verified() { return signedIn() && request.auth.token.email_verified == true; }
    function isAdmin()  { return signedIn() && request.auth.token.admin == true; }
    function d()        { return request.resource.data; }
    function changes(keys) { return d().diff(resource.data).affectedKeys().hasOnly(keys); }
    function str(v, min, max) { return v is string && v.size() >= min && v.size() <= max; }
    function store(c)   { return get(/databases/$(db)/documents/stores/$(c)).data; }
    function isOwner(c) {
      return verified() && store(c).ownerUid == request.auth.uid && store(c).status != 'suspended';
    }

    // ---------- 사장님 계정 ----------
    match /users/{uid} {
      allow read: if signedIn() && request.auth.uid == uid;
      allow create: if signedIn() && !isAnon() && request.auth.uid == uid
        && d().keys().hasOnly(['storeCode','uiLang','agreed','createdAt'])
        && d().agreed.age14 == true && d().agreed.terms is string && d().agreed.privacy is string
        && d().createdAt == request.time
        && getAfter(/databases/$(db)/documents/stores/$(d().storeCode)).data.ownerUid == uid;
      allow update: if signedIn() && request.auth.uid == uid && changes(['uiLang','agreed']);
      allow delete: if signedIn() && request.auth.uid == uid;
    }

    // ---------- 가게 ----------
    match /stores/{code} {
      function validSettings() {
        return str(d().storeName, 1, 30) && str(d().intro, 0, 60)
          && d().acceptingQuestions is bool && d().showUnanswered is bool
          && d().blockedWords is list && d().blockedWords.size() <= 30;
      }

      allow read: if true;

      allow create: if signedIn() && !isAnon()
        && code.matches('^[23456789abcdefghjkmnpqrstuvwxyz]{8}$')
        && d().keys().hasOnly(['storeName','intro','ownerUid','lang','status',
                               'acceptingQuestions','showUnanswered','blockedWords','createdAt'])
        && d().ownerUid == request.auth.uid && d().status == 'pending'
        && d().createdAt == request.time && validSettings()
        && !exists(/databases/$(db)/documents/users/$(request.auth.uid))           // 계정당 가게 1개
        && getAfter(/databases/$(db)/documents/users/$(request.auth.uid)).data.storeCode == code;

      allow update: if
        (isOwner(code)
          && changes(['storeName','intro','lang','acceptingQuestions','showUnanswered','blockedWords','status'])
          && validSettings()
          && (d().status == resource.data.status
              || (resource.data.status == 'pending' && d().status == 'active')
              || (resource.data.status == 'active'  && d().status == 'deleted')))
        || (isAdmin() && changes(['status']) && d().status in ['active','suspended']);

      allow delete: if false;                                                       // 코드 재사용 금지

      // ---------- 질문 ----------
      match /questions/{qid} {
        function authorPath()   { return /databases/$(db)/documents/stores/$(code)/authors/$(qid); }
        function throttlePath() { return /databases/$(db)/documents/throttle/$(request.auth.uid); }
        function reportPath()   { return /databases/$(db)/documents/reports/$(qid + '_' + request.auth.uid); }

        allow read: if resource.data.hidden == false || isOwner(code) || isAdmin();

        allow create: if signedIn()
          && store(code).status == 'active' && store(code).acceptingQuestions == true
          && !exists(/databases/$(db)/documents/stores/$(code)/blocked/$(request.auth.uid))
          && d().keys().hasOnly(['body','lang','status','answer','hidden','hiddenBy',
                                 'reportCount','pinned','createdAt'])
          && str(d().body, 2, 500) && str(d().lang, 2, 10)
          && d().status == 'open' && d().answer == null
          && d().hidden == false && d().hiddenBy == null
          && d().reportCount == 0 && d().pinned == false
          && d().createdAt == request.time
          && getAfter(authorPath()).data.uid == request.auth.uid                    // 작성자 기록 같이
          && getAfter(throttlePath()).data.lastPostAt == request.time               // 쓰기 간격 기록 같이
          && (!exists(throttlePath())
              || get(throttlePath()).data.lastPostAt < request.time - duration.value(30, 's'));

        allow update: if
          // 사장님: 답변 · 숨기기 · 고정 (운영자가 가린 건 못 풂)
          (isOwner(code) && resource.data.hiddenBy != 'admin'
            && changes(['answer','status','hidden','hiddenBy','pinned'])
            && (d().answer == null
                  ? d().status == 'open'
                  : (str(d().answer.body, 1, 1000) && d().status == 'answered'))
            && d().hidden is bool && d().pinned is bool)
          // 손님 신고: 한 사람당 한 번, 3건부터 자동 가림
          || (signedIn() && changes(['reportCount','hidden','hiddenBy'])
            && !exists(reportPath()) && existsAfter(reportPath())
            && d().reportCount == resource.data.reportCount + 1
            && (d().reportCount >= 3
                  ? (d().hidden == true && d().hiddenBy == 'report')
                  : (d().hidden == resource.data.hidden && d().hiddenBy == resource.data.hiddenBy)))
          // 운영자
          || (isAdmin() && changes(['hidden','hiddenBy']));

        allow delete: if isOwner(code) || isAdmin()
          || (signedIn() && get(authorPath()).data.uid == request.auth.uid);       // 내가 쓴 질문
      }

      // ---------- 작성자 기록 (차단 · 본인 삭제용) ----------
      match /authors/{qid} {
        allow create: if signedIn()
          && d().keys().hasOnly(['uid']) && d().uid == request.auth.uid
          && !exists(/databases/$(db)/documents/stores/$(code)/questions/$(qid))
          && existsAfter(/databases/$(db)/documents/stores/$(code)/questions/$(qid));
        allow read:   if isOwner(code) || (signedIn() && resource.data.uid == request.auth.uid);
        allow delete: if isOwner(code) || isAdmin() || (signedIn() && resource.data.uid == request.auth.uid);
      }

      // ---------- 차단 목록 ----------
      match /blocked/{uid} {
        allow read, write: if isOwner(code);
      }
    }

    // ---------- 쓰기 간격 ----------
    match /throttle/{uid} {
      allow read: if signedIn() && request.auth.uid == uid;
      allow create, update: if signedIn() && request.auth.uid == uid
        && d().keys().hasOnly(['lastPostAt']) && d().lastPostAt == request.time;
    }

    // ---------- 신고 ----------
    match /reports/{rid} {
      allow create: if signedIn()
        && d().keys().hasOnly(['targetType','storeCode','targetId','reason','detail',
                               'reporterUid','status','createdAt'])
        && d().targetType in ['question','store']
        && rid == d().targetId + '_' + request.auth.uid                             // 한 사람당 한 번
        && d().reporterUid == request.auth.uid
        && d().reason in ['abuse','privacy','spam','sexual','defamation','other']
        && str(d().detail, 0, 300)
        && d().status == 'open' && d().createdAt == request.time;
      allow read, update: if isAdmin();
    }

    match /{document=**} { allow read, write: if false; }
  }
}

손님 목록 쿼리는 규칙 때문에 반드시 where("hidden", "==", false)를 넣어야 합니다. 가려진 글은 링크를 직접 알아도 읽을 수 없어 임시조치 요건도 맞습니다.
